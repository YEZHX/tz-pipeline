# Где будет работать: Extella OS, локально или отдельно

Вопрос задаётся сразу после ТЗ, даже если ТЗ кажется полным. Ответ меняет стек, сроки и набор обязательных проверок, поэтому его не угадывают. Рекомендацию ты готовишь сам и предлагаешь вместе с вопросом.

## Три вопроса — первое «да» решает

1. **Данные должны остаться на компьютере клиента** — 1С, файлы, ключи, локальная программа? Да → **локально**.
2. **Нужна работа без открытого окна**, доступ для людей без аккаунта Extella, свой домен или поисковая выдача? Да → **отдельно**.
3. Ни то, ни другое → **Extella OS**: самый короткий путь, агент, эксперты и магазин уже есть.

Первый и третий ответ часто верны одновременно: данные на машине, интерфейс в окне Extella. Это гибрид — по канону Extella стандартный тип продукта, а не компромисс (правило H10).

## Сравнение

| Что | Extella OS | Локально, на машине клиента | Отдельно, свой стек |
|---|---|---|---|
| Когда | Клиент уже в Extella; нужен агент с экспертами и окно приложения; продажа через магазин | Данные не должны покидать машину: 1С, файлы, ключи, локальные сервисы | Публичный сайт для людей без аккаунта Extella, свой домен и бренд, работа в фоне, поисковая выдача |
| Из чего | Агент, эксперты и страница в окне ОС: HTML+JS до 3 МБ или собранный React до 20 МБ; состояние — в KV или у эксперта | В Extella — гибрид: архив с `install.py` ставит локальную часть, интерфейс — страница в окне ОС, эксперт работает на устройстве через право `device.run`. Без Extella — десктоп-приложение или скрипт | Например, Next.js, Postgres, Vercel и Claude API |
| Ограничения | Страница не работает в фоне и не хранит данные в браузере; серверного рендеринга нет; вызов эксперта с устройства — 13–17 секунд | Нужен живой слушатель на машине; `install.py` под все ОС; на чужом компьютере — паспорт продукта, урезанные права и контракт состояния | Свои авторизация, хостинг, мониторинг и оплата; агенты Extella — только через API с ключом |
| Правила канона | H5, H27, H106 | H10, H5-bis, H98, H107 | H109 — если ходить в API Extella |

Цифры и правила взяты из канона Extella на 26.10.2026. Прежде чем опираться на них в сборке, перечитай правило из первоисточника (`extella.md`): канон правится замерами.

## Примеры

- Сверка выгрузок из 1С у бухгалтера → **локально**, гибридом: данные не покидают машину, сверку делает код.
- Агент, который проверяет загруженные сотрудниками договоры → **Extella OS**.
- Публичный сайт записи к стоматологу с формой и поисковой выдачей → **отдельно**.
- Ответы клиентам в мессенджере круглосуточно → работа в фоне без открытого окна, значит **отдельно** (или связка со своим сервисом, который вызывает агента Extella через API).

## Правило в одну строку

Тип продукта определяют данные, интерфейс — частота вызовов, а нужен ли эксперт — нужна ли модель (AGENT_BUILD_GUIDE канона, §2b).
